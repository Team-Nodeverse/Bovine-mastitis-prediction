# 💻 CattleΨic Software

The CattleΨic software layer connects the Raspberry Pi edge device with the farmer-facing monitoring system.

## Software Modules

### Farmer Dashboard

The dashboard is designed to display:

- Cow-wise health records
- Latest milk-test readings
- Mastitis risk status
- Historical test results
- Device information
- Alert information

### Backend

The backend handles:

- Device data reception
- Health-record storage
- Dashboard APIs
- Cow-wise test history
- Future cloud synchronization
